# Used Car Price Prediction System

This project is a  Flask web application for predicting the price of a used car using a Linear Regression model trained in Python with Scikit-learn.


## Project Structure

```text
car_price_prediction_ml/
├── app.py
├── Car_Price_Prediction_Linear_Regression.ipynb
├── car_price_model.pkl
├── requirements.txt
├── data/
│   └── Cardetails.csv
├── static/
│   ├── css/
│   │   └── style.css
│   └── js/
│       └── script.js
└── templates/
    └── index.html
```

## Features

- Flask backend for serving the web app
- HTML, CSS, and vanilla JavaScript frontend
- Linear Regression model for price prediction
- Simple form validation and JSON-based prediction request
- Clean and responsive interface
- Notebook and saved model artifact included for reproducibility
